# Streamlit App

Ứng dụng web đơn giản xây dựng bằng **Streamlit**.

## Cách chạy ứng dụng (Windows)

### 1. Tạo môi trường ảo

```bash
python -m venv venv
```

### 2. Kích hoạt môi trường ảo

```bash
venv\Scripts\activate
```

### 3. Cập nhật pip

```bash
python -m pip install --upgrade pip
```

### 4. Cài đặt thư viện cần thiết

```bash
python -m pip install -r streamlit_app\requirements.txt
```

### 5. Chạy ứng dụng

```bash
streamlit run streamlit_app/app.py
```

Sau khi chạy xong, trình duyệt sẽ tự động mở ứng dụng Streamlit. Nếu không, kiểm tra terminal để lấy địa chỉ `localhost`.
